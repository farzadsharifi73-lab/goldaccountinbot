# ربات خصوصی گزارش معاملات طلافروشی‌ها (نسخه آزمایشی)

**مالک مجاز:** شناسه شخصی تلگرام `1508795686` (شناسه ربات نیست). این برنامه **هیچ پاسخی در گروه‌های حسابداری ارسال نمی‌کند** و فقط پیام‌های هشتگ‌دار گروه‌های مجاز را ثبت می‌کند. نتایج خصوصی برای مالک است.

## وضعیت و مرزها

- نسخه آزمایشی است؛ **هیچ تطبیق نهایی با زرحساب یا ته‌حساب انجام نمی‌شود**.
- جمع پول فقط با واحد صریح `تومان` یا `ریال` در همان سطر مبلغ استخراج می‌شود؛ ریال تقسیم بر ۱۰ می‌شود و واحد گزارش تومان است. مبلغ بدون واحد در جمع منظور نمی‌شود و خطا اعلام می‌شود.
- جمع وزن فقط با واحد صریح `گرم` یا `سوت` در همان سطر وزن استخراج می‌شود؛ سوت بر ۱۰۰۰ تقسیم می‌شود.
- مظنه عین متن گزارش می‌شود و به‌خاطر احتمال تفاوت واحد/مبنای مظنه جمع ریالی نمی‌شود.
- پیام اصلاح‌شده دوباره پردازش می‌شود؛ حذف پیام از تلگرام به‌صورت خودکار حذف رکورد دیتابیس ایجاد نمی‌کند. عکس بدون کپشن پردازش نمی‌شود؛ داده‌های عکس OCR نمی‌شوند.
- الگوریتم خواندن قالب‌های ۱۳گانه کاربر **نیاز به تست با پیام‌های واقعی دارد**؛ جمع مبلغ بر اساس همه‌ی برچسب‌های دریافتهای چندمرحله‌ای محاسبه نمی‌شود و سود و موجودی واقعی از این خروجی قابل اثبات نیست.

## راه‌اندازی فقط با گوشی، GitHub و Render

1. فایل‌های `bot.py`، `requirements.txt`، `render.yaml` و `.gitignore` را در ریشه مخزن GitHub قرار دهید. **هیچ توکنی داخل GitHub، چت عمومی یا README نگذارید.** اگر مخزن عمومی است، فقط کد بدون اطلاعات مشتری و کلیدها را بارگذاری کنید؛ بهتر است مخزن را خصوصی کنید.
2. در Render از **New > Blueprint** مخزن را انتخاب کنید، یا از **New > Web Service** متصل به مخزن استفاده کنید. برای Web Service تنظیم کنید:
   - Build command: `pip install -r requirements.txt`
   - Start command: `uvicorn bot:app --host 0.0.0.0 --port $PORT --workers 1`
   - Env: `TELEGRAM_BOT_TOKEN` = توکن موجود از BotFather؛ `OWNER_TELEGRAM_ID` = `1508795686`؛ `WEBHOOK_SECRET` = رشته تصادفی بلند لاتین (`A-Za-z0-9_-`). `ALLOWED_GROUP_IDS` ابتدا خالی.
   - اگر Render متغیر `RENDER_EXTERNAL_HOSTNAME` را تزریق نکرد، `WEBHOOK_BASE_URL` را روی آدرس https سرویس Render قرار دهید.
3. صبر نکنید که ربات در گروه پاسخ بدهد؛ طراحی عمداً گروه را ساکت نگه می‌دارد. در چت خصوصی ربات، `/start` و سپس `/ping` را ارسال کنید.
4. ربات را به **گروه حسابداری گالری ماهی** اضافه کنید. در BotFather با `/setprivacy` برای این ربات **Disable** را انتخاب کنید یا ربات را ادمین گروه کنید. اگر Privacy Mode را تغییر دادید، ممکن است لازم باشد ربات را از گروه حذف و دوباره اضافه کنید.
5. یک پیام آزمایشی با هشتگ در گروه بفرستید. در چت خصوصی ربات دستور `/groups` را بفرستید و ID منفی گروه را بردارید. در Render > Environment متغیر `ALLOWED_GROUP_IDS` را برابر این ID منفی بگذارید (برای گروه‌های بیشتر با ویرگول جدا کنید) و سرویس را redeploy کنید.
6. پس از ثبت گروه مجاز، پیام آزمایشی تازه‌ای بفرستید:
   ```
   #فروش_آبشده
   به علی رضایی
   مبلغ: ۲۵,۰۰۰,۰۰۰ تومان
   وزن: ۲.۵ گرم
   مظنه: ۴۵,۵۰۰,۰۰۰
   ```
   در خصوصی ربات دستور `/report` و `/customers` و `/quotes` را تست کنید.

## دستورها — همه فقط در خصوصی مالک

- `/ping` بررسی اتصال
- `/groups` گروه‌های شناسایی‌شده و وضعیت مجاز بودن
- `/report` گزارش روز جاری به وقت تهران
- `/report 1405/07/16` گزارش روز شمسی
- `/month 1405/07` گزارش ماه شمسی
- `/customers` فهرست مشتری‌ها/طرف‌حساب‌های امروز
- `/quotes` مظنه‌های خام امروز
- `/incomplete` سندهای نیازمند بررسی امروز
- `/export` خروجی CSV امروز و `/export all` همه رکوردهای ذخیره‌شده در پایگاه داده

## هشدار مهم برای حفظ سوابق حسابداری

**Render Free دیتابیس SQLite را حفظ نمی‌کند.** سرویس رایگان پس از بی‌کاری خاموش می‌شود و با خوابیدن/ری‌استارت فایل SQLite محلی از دست می‌رود. این نسخه صرفاً برای آزمودن عملکرد است؛ تا زمان انتقال به دیتابیس پایدار یا سرویس دارای دیسک دائمی از آمار آن برای گزارش رسمی کارفرما استفاده نکنید. خود Render Postgres رایگان نیز مهلت محدود دارد؛ برای آرشیو رسمی راه‌حل پایدار با پشتیبان‌گیری لازم است.

## امنیت

مالک بودن در برنامه با `message.from.id` و `message.chat.id` کنترل می‌شود. درخواست‌های webhook باید header محرمانه تطبیق داده‌شده با `WEBHOOK_SECRET` داشته باشند. گروه‌های غیرمجاز فقط شناسه و نامشان جهت تشخیص اولیه ذخیره می‌شود و هیچ پیام معاملاتی از آن‌ها در بانک ثبت نمی‌شود. توکن را فقط در Secrets/Environment نگه دارید. اگر جایی لو رفت در BotFather با `/revoke` توکن را عوض کنید.
